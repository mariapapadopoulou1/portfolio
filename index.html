Cancer Classification Using Multi-Instance Learning

Whole-slide pathology images are too large to process directly, so each slide was represented by thousands of pre-extracted patch features. Four multi-instance learning methods were developed in PyTorch and evaluated through five-fold cross-validation. Attention MIL made the fewest classification errors, achieving 95.5% accuracy.
